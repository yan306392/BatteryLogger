# 🔋 BatteryLogger (电池记录)

一个轻量级、无广告、完全本地运行的安卓电池监控应用。专为需要长时间抓取放电/充电数据的测试设计。

## ✨ 核心功能
- ⏱️ **精准记录**：每 10 秒记录一次时间、电压、电量，电量变化时自动触发。
- 🛡️ **防杀后台**：前台服务常驻通知，实时显示电压，防止被系统清理。
- 🔌 **全芯片兼容**：深度适配高通、MTK、展讯、ASR 等芯片平台。
- 💾 **自动保存**：数据直接保存到手机 `Download` 目录，低电量关机数据不丢。
- 📂 **防覆盖命名**：文件名为 `battery_月日时分秒_序号.csv`，多台手机同时测绝不覆盖。
- 📱 **广泛适配**：支持 Android 5.0+，适配小屏设备。

## 📊 数据格式
导出的 CSV 格式如下：
`time,Voltage,Battery level`
`14:30:05,3802,85`
