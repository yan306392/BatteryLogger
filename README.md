# 🔋 BatteryLogger (电池记录)

一个轻量级、无广告、完全本地运行的安卓电池监控应用。专为需要长时间抓取放电/充电数据的极客和测试人员设计。

## ✨ 核心功能

- ⏱️ **精准定时记录**：默认每 10 秒记录一次时间、电压、电量，电量变化时自动触发额外记录。
- 🛡️ **防杀后台**：采用前台服务常驻通知，实时显示当前电压，防系统清理。
- 🔌 **全芯片兼容**：深度适配高通、MTK、展讯、ASR 等芯片平台（底层 sysfs 多路径读取兜底）。
- 💾 **自动保存**：数据自动保存到手机 `Download` 目录，低电量关机前数据不丢失。
- 🔄 **状态防假死**：手机意外重启或关机后，界面状态自动恢复，不会卡死在“正在记录”。
- 📂 **防覆盖命名**：文件名为 `battery_月日时分秒_序号.csv`，多台手机同时测试绝对不会互相覆盖。
- 📱 **广泛适配**：支持 Android 5.0+，适配 2.4寸/2.8寸小屏设备。
